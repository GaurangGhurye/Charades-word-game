# Charades-word-game
Charades Party, a high-energy mobile gaming experience built with Flutter. This isn't just another word-guessing game; it’s a modern take on a classic, optimized for seamless, fast-paced fun.
Why you’ll like it:
Motion-Controlled Gameplay: No buttons needed—simply tilt your phone down to score or up to skip using real-time gyroscope tracking.
Massive AI Word Pools: Access thousands of non-repeating words across categories like Anime, Movies, and Tech—all available offline.
Premium Aesthetic: Features a  dark theme with neon accents, glassmorphism UI, and smooth animations.
Interruption-Free: Intelligent ad integration ensures you never see an ad during active gameplay.
Whether you are looking for a team-building icebreaker or a weekend party starter, Charades Party is built to deliver.
🚀 Tech Stack: Flutter, sensors_plus, audioplayers, and flutter_animate
